# 嗨番Agent · HiFun Agent H5

嗨番集团是一家专注于口感番茄的产业运营商。

嗨番Agent采用 React/Vite H5、Express 后端和 Pi Agent，并以 `@assistant-ui/react` 管理对话运行时和消息呈现。用户请求先进入 Agent；图片直接提供给主模型理解，Agent 可按需调用只读知识检索与续读工具。当前版本不接入正式病害诊断能力。

## 本地运行

需要 Node.js >=22.19.0，建议与 Docker 一致使用 Node 24。

```sh
npm ci
cp .env.example .env
npm run dev
```

默认 demo 模式不调用云服务，访问 http://127.0.0.1:1842。`npm run check` 执行离线测试与生产构建。真实模式需配置经授权的服务端凭据；浏览器不持有密钥，真实图片联调须明确授权具体图片和目的地。

## 产品与目录

匿名临时会话，两小时无有效交互过期；有效期内支持同浏览器恢复、单图、补图和追问。不提供账号登录或长期会话数据库。

- `src/`：Assistant UI 聊天界面、消息组件与主题。
- `server/`：匿名会话、Pi 编排、只读知识工具与清理任务。
- `skills/`：身份和业务技能规则。
- `knowledge/`：公开知识库的固定 Markdown 快照。
- `contracts/`、`tests/`：诊断契约和合成数据回归测试。
- `deploy/`、`Dockerfile`：应用打包和部署工具。

## 主模型与回答显示

当前代码接入 DeepSeek V4.1 Flash，使用模型 ID `deepseek-flash`、OpenAI 兼容接口 `https://api.deepseek.com`，服务端变量为 `MODEL_PROVIDER`、`MODEL_NAME`、`MODEL_BASE_URL`、`MODEL_API_KEY`、`MODEL_ENABLE_THINKING`、`MODEL_REASONING_EFFORT` 和 `MODEL_MAX_TOKENS`。思考模式默认开启、推理强度为 high，模型上下文窗口按官方规格配置为 1M；单段输出预算为 32,768 tokens。若正文达到模型的单次长度上限，服务端最多自动续写到四段，整个过程仍以流式文字发布。旧百炼配置仍可通过显式设置 `MODEL_PROVIDER=bailian` 回退。公众 H5 当前不加载或调用独立诊断胶囊。

DeepSeek API Key 仅通过受限的服务端运行配置提供，不能进入浏览器、Git 或镜像。真实模型调用与生产版本状态以每轮发布验收为准。

Agent 完成工具调用后，通过 complete_answer 检查回答类别和依据，随后进入无工具的正文流式生成。原始思考和工具参数不展示；前端只显示可展开的处理状态。真实来源链接由后端添加。职责硬阻断和缺少支撑资料的具体问题使用固定提示；一般知识答复会明确标注其性质。依据检查不等于逐句事实审核，流式生成仍需业务质量验收。

公众版只向 Agent 提供 `search_knowledge`、`read_knowledge` 与 `complete_answer` 三项工具。检索默认最多返回12篇、每篇摘要有长度上限；Agent 可以用互补关键词继续检索，并按章节或偏移读取已经检索到的文档。Agent 不具备 Shell/脚本执行、任意文件读写、软件安装、任意网址访问、云服务或业务数据库工具。

回答仅以聊天中的流式文字呈现，不生成报告或文件，不提供下载、预览或图表。嗨番业务事实、点名品种和明确流程须由直接相关的知识正文支撑。一般农业问题在检索确认资料不足后可以回答，但要标注“一般参考（非嗨番知识库结论）”。回答使用简明 Markdown；相关资料不足时不以一般常识补造嗨番事实、品种结论或流程。

用户停留底部时跟随新内容，主动上滑后显示回到最新入口。生成中断的片段标为未完成，不当作完成回答加入后续模型上下文。手机真机与真实模型的验收应分别进行。


## 工作范围与会话额度

主 Agent 面向嗨番公开资料、口感番茄种植/设施/采后知识与相关图片理解。范围外请求由 Agent 分类后返回固定拒答；上传图片由主模型按用户问题理解内容、场景和可见外观，用途不明先澄清。当前不提供番茄病害诊断；后续须通过独立 MCP 能力单独接入。模型分类及提示词约束不等于不可绕过的语义保证，仍须持续用实际业务案例验证。

匿名会话默认 1000 万主 Agent tokens，可用服务端 SESSION_TOKEN_LIMIT 调整。两小时无有效交互、会话过期后新会话额度重置；刷新页面和重启服务不会重置有效会话用量。换浏览器或清除 Cookie 可成为新会话，本限制不等于自然人身份限额。

服务端在 runtime/usage 保存临时用量账本，覆盖决策、工具往返、重试和正文模型调用，含缓存输入与输出；胶囊内部用量不计入。每次调用前保守预留额度，收到模型 totalTokens 后结算；失败但有用量仍结算，缺失用量保留预留。余额不足以预留下一次请求时提前停止，因此未必恰好用到最后一个 token；预留是保守估计，最终用量以服务商回执为准，不代替平台费用上限。已完成请求回放不重复调用计费。当前账本适用于单应用进程，不支持多个实例共享 runtime。
